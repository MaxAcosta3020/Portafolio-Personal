# IBM Plex local

Fuentes descargadas de Fontsource 5.3.0, mantenidas en el proyecto para evitar
peticiones externas durante el build y en el navegador.

- `plex-sans-latin.woff2`: `@fontsource-variable/ibm-plex-sans`, latin, normal, eje de peso.
- `plex-mono-latin.woff2`: `@fontsource/ibm-plex-mono`, latin, normal, peso 400.
- Licencias originales conservadas junto a los archivos.
- Diseño original: https://github.com/IBM/plex

El subconjunto latin cubre los caracteres españoles utilizados en la muestra.
Si se amplían idiomas, revisar la cobertura antes de añadir más archivos.
